
# Estruturas de Dados em Python — Pilhas e Filas

Este repositório contém os códigos desenvolvidos para a atividade prática da disciplina de Estruturas de Dados, utilizando a linguagem Python.

O objetivo da atividade é aplicar os conceitos estudados sobre pilhas e filas na resolução de diferentes problemas, compreendendo como essas estruturas organizam e manipulam elementos.

## Códigos desenvolvidos

Os códigos estão organizados na pasta `src`:

- `01_contaPar_recursivo.py` — contagem de números pares em uma pilha utilizando recursividade.
- `02_parentetização_pilha.py` — verificação de parênteses em expressões utilizando uma pilha.
- `03_inverter_fila.py` — inversão dos elementos de uma fila utilizando uma pilha auxiliar.
- `04_intercalar_filas.py` — intercalação dos elementos de duas filas, alternando entre elas.

## Conceitos praticados

- **Pilhas (LIFO):** o último elemento inserido é o primeiro a sair.
- **Filas (FIFO):** o primeiro elemento inserido é o primeiro a sair.
- **Recursividade:** utilização de chamadas de uma função para resolver um problema.
- **Verificação de parênteses:** análise da organização dos parênteses em expressões.
- **Manipulação de filas:** inversão e intercalação de elementos.
